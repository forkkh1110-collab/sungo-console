# 선고 길드 운영콘솔
포세이돈2서버 선고 길드 운영 콘솔 — GitHub Pages 호스팅 (데이터는 Google Sheets Apps Script API 실시간 연동).

- 주소: https://forkkh1110-collab.github.io/sungo-console/
- 갱신: `index.html` 수정 → 커밋 → `git push origin main` → 약 1분 뒤 반영.
- 데이터 API(`DIST_API`)는 Apps Script 웹앱 exec 주소. Code.gs 를 바꿀 때만 Apps Script 새 버전 배포가 필요.
